{% endif %} {% endif %} {% call k.explain("What to do with a leaked secret", "Rotate it first. Then remove it from the file.") %}

Rotate it. Make a new one at the service that issued it, and switch the old one off. A secret that was sent to a model provider has left this machine, so removing the file does not help.

Then remove it from the file. Curb replaces the secret with a placeholder of the same length. There is no backup and no undo, because a backup would be another copy of the secret.

Check which still work sends each secret to its own issuer, and nowhere else. It asks you first.

Sent
It is in an agent's transcript, so the model provider received it.
Readable
It is in a file an agent can read, but no agent has sent it.
Blocked
It is on disk, and a setting stops every agent reading it.
