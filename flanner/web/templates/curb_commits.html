{% endblock %} {% block reviews %} {% call k.review_box("signing", "Set up commit signing?", "/curb/projects/commits/signing") %}

Curb gives each agent a signing key of its own, kept in your operating system's credential store.

  • Each agent's settings change, so git signs its commits with that key.
  • Curb's logging hooks are added too: a key signs only inside a session they recorded.
  • Your own commits are not changed.

Curb backs up each settings file for 7 days. Undo is under Fixes.
