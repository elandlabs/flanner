{% call k.explain("What a fix changes", "Only each agent's own settings, and only to make them stricter.") %}
Sandbox
A fence around the commands an agent runs. It limits the files and sites they can reach.

A fix edits the settings file that belongs to you, for one agent. It never edits a project, and it never loosens anything. If Curb cannot show that a change only tightens, it leaves the change out and says why.

Before it writes, Curb copies each file to a backup that no agent can read, and keeps it for 7 days. Undo puts the copy back.

These fixes cover the credentials every project shares. To close one project's own files too, such as its .env file, run this inside the project:

{{ k.cmd("flanner curb fix") }} {% endcall %}
