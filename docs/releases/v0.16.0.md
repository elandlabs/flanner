# v0.16.0

A release about what your agents can reach, and about talking to your
team. Flanner Curb arrives whole, messages between teammates arrive, and
a desktop app bundles it all. The full list is in the
[changelog](../../CHANGELOG.md#0160---2026-10-07).

There was no 0.15.0 on PyPI. The messaging work planned for it ships here,
beside Curb, under the number Curb's own commands already carried.

## Flanner Curb

`flanner curb map` shows what Claude Code and Codex can reach on this
machine: the credentials each could read, and every channel that could
carry them away. It rates each launch High, Medium or Low, with the rule
behind the rating and which setting would close each open channel.

- `flanner curb sweep` finds secrets agents left behind, in transcripts,
  sessions, settings, shell history and `.env` files. It prints counts only.
  Detection needs the `flanner[sweep]` extra.
- `flanner curb fix` closes what an agent can reach, in that agent's own
  settings, after your operating system asks you for a yes. `--dry-run`
  shows the plan and `--undo` puts the files back.
- `flanner curb test` proves a block by asking the agent itself to get past
  it. `flanner curb scrub` replaces a rotated secret in a file.
- `flanner curb log --enable` records each tool call's metadata, never its
  content, in a signed, hash-chained log. `flanner curb observed` says what
  each agent has been seen using.
- `flanner curb ci` judges the agent steps in a repository's GitHub Actions
  workflows, and the same check is the `elandlabs/flanner/actions/curb-ci`
  action. `flanner curb app` finds an application's own LLM calls.
- `flanner init` installs the `agent-blast-radius` skill, so an agent can
  run the redacted commands and ask you for the rest.
- The web UI has a Curb section at `/curb`, redacted as the terminal is.

No command prints a credential's name, location or value, whoever runs
it. `flanner curb show` opens names and locations in a window on your own
screen. Everything above runs locally and needs no account.

With Flanner Mesh, a team gets more, free on every plan: one signed agent
policy (`flanner curb policy`), a fleet view of each device's state
(`flanner curb fleet`), alerts when an agent's reach grows, and
per-agent commit signing keys with `flanner curb attribution` and
`flanner curb verify`. The control plane must offer them; one from before
Curb is told apart and said so.

## Messages between teammates

`flanner messages send`, `inbox`, `reply` and `broadcast` go straight to
your teammates' devices, never through a server. Every send is previewed
first. The web UI has a Messages page, and after `flanner init` a new
message appears in your Claude Code or Codex session as data, not as an
instruction. `flanner peer autostart on` keeps receiving across reboots.
Needs Team Mesh with messaging switched on in the console.

## Fixed

- Help examples that failed as written now run.

  what they edit.

  version does not expect.
- A message no longer waits a day on a teammate's removed device.
- Windows Hello is asked at all: its script never parsed before.

## Security

Curb's approval prompt is run from the place the operating system
installs it, with an environment of Curb's own. Before this release a
shell that set PATH and planted a program by the prompt's name could have
answered its own approval.

## Upgrading

```bash
pip install -U flanner
```

The database gains the messages tables. The first command after the
upgrade migrates it. Restart any `flanner peer serve`, web UI or
`flanner-mcp` started before the upgrade: they refuse to write until you
do, and lose nothing. The leak sweep needs `pip install -U 'flanner[sweep]'`.

## Checks by hand

Recorded on 2026-10-07, as ADR 0006 and the Curb PRD's exit criteria ask.
Everything below ran against a machine made up for the purpose: fake
credential files, fake agent settings, planted transcripts. Nothing real
was read.

- **Keyboard pass, web UI (Windows).** Every Curb part was walked by Tab
  with Playwright: each control is reached, the focus ring shows, Enter
  opens a review and Escape closes it, and no part has more than one main
  button. Links inside a closed expander are reached once it is opened.
  An axe-core pass at WCAG 2.1 AA found one issue, a footnote link told
  apart by colour alone, fixed in `2408214`. No person has driven a screen
  reader through the pages yet.
- **Leak sweep budget (Windows 11 laptop).** On 2,505 planted files, about
  60 MB of transcripts, sessions and shell history, the sweep took 46.6 s
  and peaked at 73 MB across its processes. On 505 files, 14.6 s and
  75 MB. The PRD asks for under 2 minutes and under 500 MB.
- **A real agent ran the skill.** Claude Code 2.1.293 ran
  `agent-blast-radius` headless, read-only, 9 turns, USD 0.45. Its
  transcript holds no path, no credential name, no secret value and no
  user name; the report gives counts and settings only.
- **Still to do by a person:** the R3 design gate, that synthetic keyboard
  and mouse input cannot complete an approval, on Windows, macOS and
  Linux; `flanner curb test` with a real agent, which needs an approval;
  the action log's hook payloads checked against a real session; and the
  ADR 0008 threat model review. The Windows check: open a fix's review
  in the web UI, let the prompt appear, and from another window send
  Enter and a typed password with `SendKeys`; the prompt must stay
  unsatisfied, and a password-only machine must be reported as weaker.
